📌 Project Title
End-to-End Sales Performance Dashboard — Executive Wise Analysis

📝 Short Description
A comprehensive Excel-based sales dashboard that tracks and compares sales executive performance across 8 Indian cities. Analyzes total sales, target hit percentage, and gap-from-target metrics — giving managers a 360° view of team performance through 4 interactive dashboards in a single workbook.

🎯 Purpose
This project was built to:

Compare sales executive performance across cities (Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, Surat)
Identify top performers and underperformers by target hit %
Track how far each executive is from their sales target
Practice end-to-end dashboard building — from raw data to final business insights


🛠️ Tech Stack
ToolUsageMicrosoft ExcelFull dashboard design and data sourceExcel ChartsBar chart, Pie chart, Line chartExcel SlicersCity-wise interactive filteringConditional FormattingPerformance highlightingPivot TablesData summarization and aggregation

✨ Features & Highlights
🏙️ City-wise Slicer Filter
8 city buttons (Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, Surat) — click any city to filter entire dashboard instantly.
📋 Dashboard 1 — Total Sales Ranking
Sales executive wise total sales leaderboard with bar chart visualization. Top performer: Syed Saqib (369 units).
📋 Dashboard 2 — Comparative Sales Table
Second set of executives ranked by total sales (Meena Zinjare, Pankaj Shelkey, Ravinder Kaur, Sapna Sharma, Shephali Jain).
🎯 Dashboard 3 — Target Hit % Wise
Pie chart showing each executive's share of target achievement. Top: Syed Saqib at 73.80%.
📉 Dashboard 4 — Away From Target % Wise
Line chart showing gap percentage for executives — helps identify who needs coaching. Highest gap: Pankaj Shelkey at 68.80%.

💡 Key Insights

Syed Saqib is the top performer — 369 total sales and 73.80% target hit rate
Pankaj Shelkey has the highest away-from-target gap — 68.80%
